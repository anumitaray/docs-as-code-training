# Step 5: Use Plan Mode for Bigger Changes

> Part of the [Cursor Quickstart Guide](./quickstart.md)

When working on larger features that span multiple files, require architecture research, or need user validation prior to coding, activate **Plan Mode**.

## How to Activate Plan Mode

In the Agent input bar, press:
- `Shift + Tab` to toggle Plan Mode on or off.

## Plan Mode Workflow

Instead of making changes immediately, Cursor follows a structured four-stage workflow:

1. **Codebase Research**: Identifies relevant files, database schemas, and shared utilities.
2. **Clarification**: Prompts you about edge cases, preferred patterns, and requirement specifics.
3. **Plan Creation**: Formulates a detailed checklist and design rationale.
4. **Approval Gate**: Waits for your review and explicit go-ahead before modifying code.
