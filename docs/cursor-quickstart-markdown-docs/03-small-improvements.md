# Step 3: Make One Small Change

> Part of the [Cursor Quickstart Guide](./quickstart.md)

Once you understand the architecture of the project, ask Cursor to propose a few safe, incremental improvements. Choose one proposal and instruct it to execute the modification.

## Recommended Starter Prompt

```text
Suggest three small, safe improvements in this codebase. Explain the tradeoffs and wait for me to choose one.
```

## Best Practices for Initial Edits

- **Focus on low-risk changes**: Ideal first tasks include:
  - Copywriting refinements and error message clarity.
  - Adding explicit TypeScript interfaces or Python type hints.
  - Correcting minor CSS styling or layout spacing bugs.
  - Adding documentation comments and function docstrings.
- **Direct requests**: If you already know what you want to change, ask Cursor directly with clear specifications and desired outcomes.
