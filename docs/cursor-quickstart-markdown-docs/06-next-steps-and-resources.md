## Essential Keyboard Shortcuts

| Shortcut (macOS) | Shortcut (Windows/Linux) | Action |
| :--- | :--- | :--- |
| `Cmd + I` | `Ctrl + I` | Open Agent Window |
| `Shift + Tab` | `Shift + Tab` | Toggle Plan Mode in Agent |
| `Cmd + K` | `Ctrl + K` | Inline Code Edit / Prompt in Editor |
| `Cmd + L` | `Ctrl + L` | Open Chat Sidebar |
| `@` | `@` | Mention context (Files, Folders, `@Docs`, `@Web`, Git) |
